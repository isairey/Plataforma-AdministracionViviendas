# 🌌 Acerca del proyecto

**House Rental Platform** es un sistema web orientado a la administración y búsqueda de propiedades en renta, diseñado para automatizar la gestión inmobiliaria mediante una interfaz moderna y eficiente.

La plataforma fue desarrollada para:

- 🏠 Gestionar propiedades
- 👥 Administrar usuarios
- 📍 Publicar viviendas
- 📅 Controlar alquileres
- 🔍 Buscar propiedades
- 💳 Gestionar pagos
- 🔐 Administrar accesos
- 🌐 Optimizar procesos inmobiliarios

# 🚀 Configuración del proyecto

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/Plataforma-AdministracionViviendas.git
```

---

## 2️⃣ Mover archivos

Copiar proyecto hacia:

```bash
xampp/htdocs/Plataforma-AdministracionViviendas/
```

---

## 3️⃣ Crear base de datos

Crear base:

```bash
house_rental_platform
```

---

## 4️⃣ Importar SQL

Importar:

```bash
database/house_rental_platform.sql
```

---

## 5️⃣ Configurar conexión

Editar:

```bash
includes/config.php
```

Agregar:

```php
define('DB_HOST','localhost');
define('DB_USER','root');
define('DB_PASS','');
define('DB_NAME','house_rental_platform');
```

---

## 6️⃣ Ejecutar proyecto

Abrir:

```bash
http://localhost/HouseRentalPlatform/
```
